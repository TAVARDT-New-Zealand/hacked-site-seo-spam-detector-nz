## Forensic Audit and SEO Compromise Capabilities

* **Differential Cloaking Detection**: Automated side-by-side inspection of web content served to Googlebot versus standard users.
* **Hidden Keyword and Link Injections**: Discovery of obscured content, deceptive CSS positioning, and rogue anchor farms.
* **Conditional Redirection Mechanics**: Tracking unauthorized redirects intended to divert search engine traffic.
* **Site Integrity Rating**: Quantified 0 to 100 rating accompanied by prioritized remediation procedures.

## Installation and Execution

Requires Python 3.8 or higher with standard library.

```bash
git clone https://github.com/TAVARDT-New-Zealand/hacked-site-seo-spam-detector-nz.git
cd hacked-site-seo-spam-detector-nz
python seo_spam_detector.py example.co.nz
```

For JSON output:

```bash
python seo_spam_detector.py example.co.nz --json
```
